# 작업 기록

## 2026-10-23 — v2 메타데이터를 .csync/로 통합

- 새 작업공간의 매핑·작업공간 설정·제외 규칙은 각각 `.csync/mapping.json`, `.csync/workspace.json`, `.csync/ignore`에 저장한다. `.env`와 문서 루트·매핑 키의 기준은 유지한다.
- 공통 메타데이터 경로 해석을 CLI push·pull·remap·상위 루트 탐색·중첩 경계·제외 규칙·참조 링크·웹 어댑터에 적용한다. `.csync/`는 문서·첨부 수집에서 제외하지만 웹 미리보기 fingerprint와 pull의 설정 변경 검사에는 포함한다.
- 기존 루트 메타데이터도 계속 읽고 같은 위치에 저장한다. `init --migrate --dry-run`으로 확인한 후 `init --migrate`로 명시적으로 이전한다. 전체 경로와 기존 JSON을 먼저 검사하고 복사·내용 검증 후 원본을 제거한다. 문서·첨부·.env와 중첩된 다른 작업공간은 이전하지 않는다.
- 기존·새 파일 내용이 다르거나 메타데이터 경로가 심볼릭 링크이면 거부한다. 동일한 복사본만 있는 중간 상태는 재실행 가능하며 명시적 `--mapping` 경로는 유지한다. 원격 호출과 경로·해시 재계산을 하지 않는다.
- README·CHANGELOG·CLI 및 웹 도움말에 기본 구조와 이전 방법을 반영했다. v2.0.0 PR에 포함하며 실제 사용자 문서·설정은 변경하지 않는다.
- 전체 `npm test` 238개, 빌드·CLI 도움말·`git diff --check` 통과. 새 위치·구형 호환·이전 미리보기·바이트 보존·충돌·손상 파일·심볼릭 링크·참조 링크·웹 미리보기 무효화 등 15개 전용 테스트를 추가했다. Confluence는 mock 응답으로 검증했고 테스트 HTTP 서버는 종료한다.

## 2026-10-23 — v2.0.0 작업공간·관리 범위·원격 충돌 보호

### 변경 사항

- 모든 동기화 규칙을 CLI/공통 모듈에 둔다. Git식 새 명령 체계는 추가하지 않고 기존 init·sync·pull·remap을 확장한다. 배포 웹·브라우저 인증 프로필 저장은 후속 범위다.
- `.confluence-workspace.json`에 연결과 루트·관리 경로를 저장한다. `init --scope`는 .env를 유지하며 로컬 설정만 갱신한다. CLI는 상위 작업공간을 탐색하고 해당 .env를 사용한다.
- 범위 밖 문서와 독립된 하위 매핑은 발행하지 않는다. 범위 밖 조상을 자동 생성하지 않으며, 중첩된 기존 작업공간을 관리 범위로 조용히 흡수하지 않는다. 저장된 부분 범위·연결된 루트·경로 선택에서는 rebuild를 차단한다.
- `pull --space`는 홈페이지 하위 트리를 출력 루트에 직접 연결한다. 특정 페이지·폴더는 `pull --root`로 연결한다. 페이지 ID에 대응하는 기존 로컬 경로를 재사용한다.
- 매핑에 remoteVersion을 기록한다. 변경 문서 전체의 읽기 전용 사전 검사와 갱신 직전 재확인을 수행한다. force도 원격 충돌을 우회하지 않으며, 삭제된 페이지·폴더는 자동 재생성하지 않는다. 이동 중 본문·제목 변경도 차단한다.
- `--dry-run --verify`는 원격 버전·존재를 읽기 전용으로 확인한다. 웹도 같은 옵션·저장 범위를 사용하고 작업공간 설정 변경 시 기존 미리보기를 무효화한다.
- pull은 임시 트리에서 다운로드·변환을 마친 후 로컬 문서·첨부 변경, 경로 충돌, 심볼릭 링크, 설정 동시 변경을 검사한다. 다운로드 실패 시 기존 문서를 반영하지 않는다. 빈 원격 폴더도 생성한다.
- 패키지·lockfile·CHANGELOG를 2.0.0으로 변경하고 미발행 1.9.0의 표 개선을 v2 범위에 포함했다. README와 CLI·웹 도움말에 동작 변경·이전 절차를 명시한다.

### 검증

- 전체 `npm test` 223개 통과(빌드 포함), CLI `--version` 2.0.0·도움말, `git diff --check` 통과.
- 새 작업공간 테스트의 경로 키를 POSIX 표기로 정규화해 Windows에서도 같은 매핑 기준을 사용한다. 보완 후 해당 테스트 25개를 재검증했다.
- 새 작업공간의 pull→push 무변경 왕복, 루트의 신규 페이지 부모, 저장 범위 밖 발행 차단, 독립 하위 매핑 보호, 상위 작업공간·.env 탐색을 검증했다.
- 원격 변경 사전 차단·실행 중 재검사·HTTP 409, 구형 매핑 기준 부재, 삭제/권한 오류, 이동 중 원격 수정, 로컬 변경·첨부 변경·다운로드 실패·파일명 충돌·새 출력 폴더·빈 폴더를 검증했다.
- 웹 어댑터의 범위 적용과 설정 변경 시 미리보기 무효화를 검증했다. Confluence 호출은 가짜 응답으로 가로챘으며 외부 업로드를 하지 않았다. 웹 테스트의 임시 HTTP 서버는 테스트 종료 시 닫는다.

### 적용 범위와 이전

- 사용자의 실제 문서·.env·매핑은 변경하지 않았다. 기존 중첩 작업공간과 오래된 wrapper 경로를 자동 병합·이동하지 않는다. 새 작업공간에서는 설정 복제 없이 저장 범위를 사용하며 기존 작업공간의 이전 절차는 README에 설명한다.
- 원격 버전이 없는 예전 매핑의 변경 push는 중단한다. 로컬 변경을 따로 보관한 뒤 깨끗한 문서를 pull해 기준을 확보한다. 충돌 자동 병합과 별도 비교 명령은 제공하지 않는다. 원격 첨부 파일의 독립 버전 비교는 포함하지 않는다.
- pull의 반영은 전체 사전 검사 후 파일 복사다. 디스크 쓰기 실패·프로세스 종료 시 전 파일 자동 롤백까지 보장하지 않는다. 홈페이지 밖의 별도 최상위 페이지 열거와 원격 삭제의 로컬 자동 반영은 포함하지 않는다.
- 버전 태그·npm 발행·PR 병합은 수행하지 않는다.

## 2026-10-23 — v1.9.0 표 변환 및 웹 표 서식 편집

### 변경 사항

- 전체·열 픽셀 너비와 colspan·rowspan을 Push/Pull에서 보존한다. HTML 표의 빈 줄, 문서·섹션·첨부 링크와 이미지 처리도 지원한다.
- 웹 문서 미리보기는 기본 접힘이며 펼칠 때만 요청한다. 변환·동기화 탭에서 표와 로컬 이미지를 렌더링한다. 같은 파일은 접었다 펴도 미저장 편집을 유지하고, 파일 선택이 바뀌면 이전 응답과 편집을 무효화한다.
- 표 선택·열 경계 드래그·균등 배분·전체 너비·내용에 맞춤을 제공한다. 자동 배분은 문자 길이의 75백분위와 제한된 최장 길이를 활용하는 휴리스틱이다. 넓은 문자와 병합 셀을 고려하되 실제 글꼴 픽셀 폭을 측정하지는 않는다.
- 원본·수정본을 비교한 후 여러 표의 변경을 함께 저장한다. 서버가 비교 결과를 보관하고 저장 직전 원본을 다시 확인한다. 임시 파일의 원자적 교체로 반영하며 외부 편집 충돌은 거부한다.
- 기존 토큰·Host·Origin·경로 검사를 유지한다. 문서 스크립트·외부 리소스는 제거하고, opaque-origin sandbox 안의 고정 편집 스크립트에만 nonce를 부여한다. iframe 메시지는 source와 요청별 채널로 확인한다.
- 기존 Turndown의 간접 의존성인 @mixmark-io/domino 2.2.0을 직접 의존성으로 명시했다. 패키지 및 lockfile 버전과 변경 이력은 1.9.0으로 맞췄다.

### 검증

- 최종 전체 npm 테스트 191개, 빌드, CLI 버전 1.9.0·도움말 및 diff 공백 검사를 통과했다.
- 전용 테스트는 병합 셀·CRLF·소스 범위 보존, 일반 표의 HTML 변환, 자동 너비 배분, 승인된 변경본 저장, 파일 변경 충돌, API 인증·경로 검사, 메시지 위조 거부와 비동기 UI 상태를 확인한다.
- 브라우저의 임시 사본으로 파일 선택·표 렌더링·드래그·자동 배분·비교·저장·재표시를 확인했다. 기본 접힘 동안 요청이 없고 펼칠 때 요청이 발생함도 확인했다. 검증 서버는 매번 종료했다.

### 범위와 한계

- 웹 표 편집은 픽셀 너비(열당 최소 40px·전체 최대 3000px)를 저장한다. 일반 Markdown 표는 해당 표를 HTML로 바꾼다. 중첩·목록 내부 표 등 원본 위치 대응이 불확실한 표는 편집하지 않는다.
- 미리보기는 Confluence 편집기의 재현물이 아니며 붙여넣기·서버 재저장 결과는 별도 확인 대상이다. 일반 Prettier 소스 포맷팅은 포함하지 않는다.
- 개인 문서, 임시 사본 및 브라우저 증거는 저장소에 포함하지 않는다. 이번 PR 준비에서 Confluence 업로드·npm 발행·릴리스 태그 생성은 수행하지 않는다.
