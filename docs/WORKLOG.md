# 작업 기록

## 2026-10-23 — v1.9.0 표 변환 및 웹 표 서식 편집

### 변경 사항

- 전체·열 픽셀 너비와 colspan·rowspan을 Push/Pull에서 보존한다. HTML 표의 빈 줄, 문서·섹션·첨부 링크와 이미지 처리도 지원한다.
- 웹 문서 미리보기는 기본 접힘이며 펼칠 때만 요청한다. 변환·동기화 탭에서 표와 로컬 이미지를 렌더링한다. 같은 파일은 접었다 펴도 미저장 편집을 유지하고, 파일 선택이 바뀌면 이전 응답과 편집을 무효화한다.
- 표 선택·열 경계 드래그·균등 배분·전체 너비·내용에 맞춤을 제공한다. 자동 배분은 문자 길이의 75백분위와 제한된 최장 길이를 활용하는 휴리스틱이다. 넓은 문자와 병합 셀을 고려하되 실제 글꼴 픽셀 폭을 측정하지는 않는다.
- 원본·수정본을 비교한 후 여러 표의 변경을 함께 저장한다. 서버가 비교 결과를 보관하고 저장 직전 원본을 다시 확인한다. 임시 파일의 원자적 교체로 반영하며 외부 편집 충돌은 거부한다.
- 기존 토큰·Host·Origin·경로 검사를 유지한다. 문서 스크립트·외부 리소스는 제거하고, opaque-origin sandbox 안의 고정 편집 스크립트에만 nonce를 부여한다. iframe 메시지는 source와 요청별 채널로 확인한다.
- 기존 Turndown의 간접 의존성인 @mixmark-io/domino 2.2.0을 직접 의존성으로 명시했다. 패키지 및 lockfile 버전과 변경 이력은 1.9.0으로 맞췄다.

### 검증

- 최종 전체 npm 테스트 191개, 빌드, CLI 버전 1.9.0·도움말 및 diff 공백 검사를 통과했다.
- 전용 테스트는 병합 셀·CRLF·소스 범위 보존, 일반 표의 HTML 변환, 자동 너비 배분, 승인된 변경본 저장, 파일 변경 충돌, API 인증·경로 검사, 메시지 위조 거부와 비동기 UI 상태를 확인한다.
- 브라우저의 임시 사본으로 파일 선택·표 렌더링·드래그·자동 배분·비교·저장·재표시를 확인했다. 기본 접힘 동안 요청이 없고 펼칠 때 요청이 발생함도 확인했다. 검증 서버는 매번 종료했다.

### 범위와 한계

- 웹 표 편집은 픽셀 너비(열당 최소 40px·전체 최대 3000px)를 저장한다. 일반 Markdown 표는 해당 표를 HTML로 바꾼다. 중첩·목록 내부 표 등 원본 위치 대응이 불확실한 표는 편집하지 않는다.
- 미리보기는 Confluence 편집기의 재현물이 아니며 붙여넣기·서버 재저장 결과는 별도 확인 대상이다. 일반 Prettier 소스 포맷팅은 포함하지 않는다.
- 개인 문서, 임시 사본 및 브라우저 증거는 저장소에 포함하지 않는다. 이번 PR 준비에서 Confluence 업로드·npm 발행·릴리스 태그 생성은 수행하지 않는다.
